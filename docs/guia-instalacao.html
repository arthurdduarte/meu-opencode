Guia — Instalar o pacote Meu-opencode num ambiente limpo opencode v1.18.15

Este guia restaura, numa máquina nova (ex.: após formatar), toda a configuração customizada do opencode: providers, MCP, 27 subagentes, 4 skills, o plugin graphify e o .opencode/ do projeto Rio Verde Concurso.

Antes de começar — é preciso ter git, curl e internet. O pacote não contém segredos (chaves de API) nem o binário do opencode — eles são restaurados/sanitizados como explicado nos passos 3 e 4.
Sumário 1. O que este pacote restaura 2. Pré-requisitos do sistema 3. Obter o pacote e preencher os segredos 4. Instalar (install.sh) 5. Verificar a instalação 6. Restaurar o .opencode/ do projeto concurso (opcional) 7. Pós-instalação: login, MCP e skills 8. Solução de problemas

1. O que este pacote restaura

Uma instalação recém-instalada do opencode traz apenas os agentes built-in (build, plan, general, explore) e nenhuma configuração. O pacote adiciona tudo isto:

27
Agentes globais
6 jarvis-* + 15 manas-* + 6 sec-* (pipeline web, knowledge graph, pentest)
4
Skills globais
graphify, jarvis-web-team, manas-ciel, sec-audit-team
1
MCP habilitado
gitnexus (npx); context7/github desabilitados
1
Provider
9router local (Combo01) como modelo default

Além disso: o plugin graphify.js (hook que sugere o knowledge graph em comandos bash), o PATH do opencode no ~/.bashrc e — opcional — os 15 agentes revisor-*, 12 commands, 2 prompts e 5 skills openspec-* do projeto concurso.

2. Pré-requisitos do sistema

Na máquina nova, instale o essencial:

sudo apt update
sudo apt install -y git curl nodejs npm python3 python3-pip pipx
pipx ensurepath && source ~/.bashrc
Por quê — node/npm são usados pelo MCP gitnexus (roda via npx); pipx instala a skill graphify (binário graphify).

3. Obter o pacote e preencher os segredos

1Clone/abre o pacote 
git clone <url-do-repo-Meu-opencode> ~/Projects/Meu-opencode
cd ~/Projects/Meu-opencode

Se você só tem o diretório (pen drive / backup), copie-o para ~/Projects/Meu-opencode.

2Preencha os placeholders de segredos

Edite estes dois arquivos e troque os placeholders pelas suas chaves reais:

# ~/Projects/Meu-opencode/backup/config-global/opencode.jsonc
"CONTEXT7_API_KEY": "SEU_CONTEXT7_API_KEY"     # → sua chave context7
"Authorization": "Bearer SEU_GITHUB_TOKEN"     # → seu GitHub PAT
"apiKey": "SUA_OPENAI_API_KEY"                 # → sua chave OpenAI

# ~/Projects/Meu-opencode/backup/config-global/opencode.json
"apiKey": "SUA_CHAVE_9ROUTER"                  # → chave do seu 9router (ex.: sk_9router)
Alternativa automática — em vez de editar, exporte as env vars e o install.sh substitui sozinho: OPENCODE_CONTEXT7_API_KEY, OPENCODE_GITHUB_TOKEN, OPENCODE_OPENAI_API_KEY, OPENCODE_9ROUTER_KEY.

As chaves context7 e github estão em MCPs desabilitados — pode deixá-las com placeholder se não for usá-las.

4. Instalar (install.sh)

3Rode o instalador 
./install.sh --dry-run    # 1º: veja o que será feito (nada muda)
./install.sh              # 2º: aplica de verdade

O instalador executa 5 passos:

PassoO que fazObservação
1/5Baixa o binário do opencode (script oficial) para ~/.opencode/binPula se já instalado; use --skip-binary para forçar pular
2/5Copia config global → ~/.config/opencode/ (json, jsonc, agent/, skills/)Faz backup automático do arquivo existente
3/5Copia o plugin graphify.js → ~/.opencode/plugins/ e adiciona o PATH no ~/.bashrcPATH só é adicionado se ainda não existir
4/5Instala graphifyy via pipx (skill graphify)Pula se graphify já existir
5/5Substitui placeholders de segredos por env vars (se exportadas)Avisa quais continuam pendentes

5. Verificar a instalação

4Checagem pós-instalação 
./scripts/verificar.sh

Confere binário e versão, config global, os 27 agentes, as 4 skills, o plugin graphify, o PATH e as dependências. Esperado: 18 ok, 0 falhas.

6. Restaurar o .opencode/ do projeto concurso (opcional)

O .opencode/ do repo Rio Verde Concurso (agentes revisor-*, commands corrigir-dia*, prompts fase2-v2*, skills openspec-*) é específico do projeto, então é aplicado dentro do repositório, não globalmente:

cd /caminho/para/Projeto-Concurso-RioVerde2026
~/Projects/Meu-opencode/scripts/aplicar-projeto.sh .

Também dá para usar ./install.sh --com-projeto para copiar para o diretório atual.

7. Pós-instalação: login, MCP e skills

  1. Login: o pacote não copia ~/.local/share/opencode/auth.json. Refazer: 
    opencode auth login
  2. Recarregue o shell para pegar o PATH novo: 
    source ~/.bashrc
opencode --version        # deve mostrar 1.18.x
  3. MCP gitnexus: habilitado no opencode.jsonc; na 1ª execução o opencode baixa o pacote via npx automaticamente.
  4. Skill graphify: instalei o binário via pipx (passo 4). O índice do grafo (graphify-out/) é por projeto — rode graphify index dentro de cada projeto quando quiser.
  5. Reinicie o opencode para carregar toda a config nova.

8. Solução de problemas

SintomaCausa provávelCorreção
opencode não abre / erro de configPlaceholder de segredo não preenchido ou JSON quebradoEdite ~/.config/opencode/opencode.json*. Em emergência use OPENCODE_DISABLE_PROJECT_CONFIG=1
graphify não encontradopipx ausente ou pipx ensurepath não rodadopipx install graphifyy e reabra o shell
MCP gitnexus não conectanode/npm ausentesudo apt install -y nodejs npm
Modelo 9router não respondeSeu servidor local não está rodando na máquina novaSuba o 9router em 127.0.0.1:20128 ou troque baseURL/model em ~/.config/opencode/opencode.json
Skills não aparecem no TUIopencode ainda aberto na sessão antigaSaia e abra de novo (config não é hot-reloaded)
